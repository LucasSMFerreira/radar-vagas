# Radar de Vagas

Coleta vagas de back-end, automação e IA, ordena pela compatibilidade com o meu perfil usando embeddings e envia as melhores no Telegram.

## Rodar os testes

    python3 -m venv .venv && source .venv/bin/activate
    pip install -r requirements.txt
    pytest -v
